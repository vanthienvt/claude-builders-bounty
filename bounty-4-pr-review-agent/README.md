# Claude PR Review Agent CLI + GitHub Action (`Closes #4`)

Automated Pull Request reviewer for GitHub repositories with structured Markdown output, inline file/line severity grading (`CRITICAL`, `WARNING`, `SUGGESTION`), and GitHub Actions integration.

## Usage
```bash
node bounty-4-pr-review-agent/claude-review.mjs --pr https://github.com/owner/repo/pull/123
```
